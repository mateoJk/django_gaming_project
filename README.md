# Gaming Project

A Django project for a university course. Videogames catalog with admin panel.

## How to run

1. Install dependencies:
   ```
   pip install django
   ```

2. Run migrations:
   ```
   python3 manage.py migrate
   ```

3. Start server:
   ```
   python3 manage.py runserver
   ```

## Admin credentials

- Username: `admin`
- Password: `admin123`

## URLs

- `/` — Welcome page
- `/videogames/` — Videogames catalog
- `/admin/` — Admin panel
